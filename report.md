Відповіді на запитання

1. Адреса сторінки: http://127.0.0.1:5500/index.html. Вона складається з протоколу (http), адреси хоста (127.0.0.1 — мій власний комп'ютер), порту (5500, на якому працює Live Server) і шляху до файлу (/index.html).

2. Браузер зробив кілька запитів: спочатку index.html, а потім, прочитавши HTML, окремо logo.png, бо кожен ресурс (картинка, скрипт, стиль) завантажується окремим HTTP-запитом. Ще додаються запити, які робить сам Live Server для автооновлення сторінки.

3. Картинка не показалась, замість неї з'явився текст з атрибута alt «Логотип TaskBoard». У Network запит до logo1.png став червоним зі статусом 404, бо сервер не знайшов такого файлу.

4. DevTools змінюють лише копію сторінки (DOM), яка вже завантажена в браузер, а не сам файл index.html на диску. Після F5 браузер знову запитує файл у сервера і отримує оригінальну версію, тому зміни зникають.

5. Клієнт — це браузер, який надсилає запити. Сервер — Live Server, запущений на моєму комп'ютері (127.0.0.1:5500), який відповідає на запити і віддає файли index.html, logo.png тощо.


Лабораторна 4. Git у терміналі

1. Що змінилося у виводі git status після git add?
Файл перейшов зі списку Untracked (червоний) до списку Changes to be committed (зелений), тобто потрапив в індекс і буде включений у наступний commit. Інші файли залишилися невідстежуваними.

2. Що показує git diff?
Він показує різницю між робочими файлами та останнім збереженим станом: рядки з + додані, рядки з - видалені.

3. Чим відрізняється git switch main від git merge?
git switch main лише перемикає на гілку main, і робочі файли стають такими, як в останньому commit цієї гілки. git merge вливає зміни з іншої гілки в поточну, тобто об'єднує їхню історію.

4. Чому виник конфлікт і як ти його розв'язав?
Конфлікт виник, бо в гілках main і ukr-title я по-різному змінив той самий рядок із заголовком <h1>, і Git не знав, який варіант залишити. Я поєднав обидва варіанти в <h1>Дошка завдань: керуй завданнями</h1>, видалив службові рядки <<<<<<<, ======= і >>>>>>>, потім зробив git add і commit.

5. Скільки commit-ів у твоїй історії?
До фінального commit зі звітом у історії 6 commit-ів, разом із ним буде 7. Вивід git log --oneline:
