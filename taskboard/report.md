Таблиця Network (після F5)

Запит (Name)   | Метод | Статус | Тип      | Розмір
index.html     | GET   | 200    | document | ~1 kB
logo.png       | GET   | 200    | png      | ~5 kB
about.html — не завантажується, поки не натиснути посилання.
(Live Server також підключає свій скрипт для автооновлення та WebSocket-з'єднання — вони теж видно в Network.)

При неправильному шляху images/logo1.png у Network з'являється червоний запит logo1.png зі статусом 404 (Not Found).

Відповіді на запитання

1. Адреса сторінки: http://127.0.0.1:5500/index.html. Вона складається з протоколу (http), адреси хоста (127.0.0.1 — мій власний комп'ютер), порту (5500, на якому працює Live Server) і шляху до файлу (/index.html).

2. Браузер зробив кілька запитів: спочатку index.html, а потім, прочитавши HTML, окремо logo.png, бо кожен ресурс (картинка, скрипт, стиль) завантажується окремим HTTP-запитом. Ще додаються запити, які робить сам Live Server для автооновлення сторінки.

3. Картинка не показалась, замість неї з'явився текст з атрибута alt «Логотип TaskBoard». У Network запит до logo1.png став червоним зі статусом 404, бо сервер не знайшов такого файлу.

4. DevTools змінюють лише копію сторінки (DOM), яка вже завантажена в браузер, а не сам файл index.html на диску. Після F5 браузер знову запитує файл у сервера і отримує оригінальну версію, тому зміни зникають.

5. Клієнт — це браузер, який надсилає запити. Сервер — Live Server, запущений на моєму комп'ютері (127.0.0.1:5500), який відповідає на запити і віддає файли index.html, logo.png тощо.
